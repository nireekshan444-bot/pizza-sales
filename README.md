🍕 Pizza Sales Analysis | Data Analytics Project
📌 Project Overview

This project focuses on analyzing pizza sales data to uncover meaningful business insights, understand sales performance, and identify customer ordering trends.

The analysis was performed using SQL, Microsoft Excel, Power BI, and Python to explore the dataset, calculate key performance indicators (KPIs), identify sales patterns, and create interactive visualizations.

The goal of this project is to transform raw sales data into actionable insights that can help a business make data-driven decisions.

🎯 Project Objectives
Analyze overall pizza sales performance.
Calculate key performance indicators (KPIs).
Identify the best-selling and least-selling pizzas.
Analyze sales trends by day, month, and time.
Understand customer ordering patterns.
Compare sales performance across pizza categories and sizes.
Build an interactive Power BI dashboard to visualize business performance.
Use Python for data exploration and analysis.
🛠️ Tools & Technologies
SQL: Data querying, aggregation, joins, and KPI calculations.
Microsoft Excel: Data cleaning, data analysis, pivot tables, and charts.
Power BI: Interactive dashboards, data visualization, and business reporting.
Python: Data analysis and exploration using libraries such as Pandas, NumPy, and Matplotlib, where applicable.
📊 Key Performance Indicators (KPIs)

The project focuses on the following business metrics:

Total Revenue: Total sales generated from pizza orders.
Total Orders: Number of orders placed.
Total Pizzas Sold: Total quantity of pizzas sold.
Average Order Value: Average revenue generated per order.
Average Pizzas Per Order: Average number of pizzas purchased per order.
